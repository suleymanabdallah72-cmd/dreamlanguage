First-time setup required

Connect your Supabase project

This app is production-ready, but it needs your own Supabase URL and publishable/anon key.

1Create a Supabase project.
2Run supabase/schema.sql in the SQL Editor.
3Copy config.example.js to config.js and paste your project URL and anon key.
4Create your first user in Supabase Authentication, then set that profile role to admin.
